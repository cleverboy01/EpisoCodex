## تفاوت اصلی این پروژه چیست؟

این پروژه بر پایه الگوهای پیشرفته **grok-build** بازطراحی شده است. بیشتر ابزارهای دستیار برنامه‌نویسی فقط یک دستورالعمل (System Prompt) ساده هستند، اما **EpisoCodex** با الگوبرداری از ساختار خودگردان grok-build، یک **سیستم‌عامل هوشمند برای دستیار هوش مصنوعی شماست**:

| ویژگی | ابزارهای معمولی هوش مصنوعی | معماری مبتنی بر Grok-Build (EpisoCodex) |
|---|---|---|
| **انتخاب مهارت‌ها** | دستی و ایستا | **مسیریابی هوشمند** از طریق روتِر معنایی مهارت‌ها |
| **یادگیری از اشتباهات** | وجود ندارد | **حافظه RLHF و بازخورد پویا** — جلوگیری از تکرار مجدد خطاها |
| **مدیریت کانتکست** | بدون کنترل و پرهزینه | **سپر فشرده‌ساز توکن** و خوانش جراحی‌شده کدهای حجیم |
| **اعمال تغییرات کد** | مستقیم و بدون تست | اجرای **سندباکس شبیه‌سازی شده** و اعتبارسنجی پیش از اعمال تغییر |
| **تداوم نشست‌ها** | فراموشی پس از بستن IDE | **حافظه اپیزودیک تداوم‌یافته** در دیتابیس محلی |
| **بهینه‌سازی خودکار** | نیاز به بازبینی دستی | **موتور خود‌بازنویسی** جهت بهبود مستمر کیفیت کد |
| **مدیریت وظایف** | کاملاً وابسته به کاربر | **حلقه خودگردان (Self-Healing Loop)** برای ارزیابی و کشف باگ‌ها |

## شروع سریع

```bash
# ۱. کلون کردن مخزن
git clone [https://github.com/cleverboy01/EpisoCodex.git](https://github.com/cleverboy01/EpisoCodex.git)
cd EpisoCodex

# ۲. راه‌اندازی با یک کلیک (ساخت دیتابیس‌ها، ایندکس مهارت‌ها و نصب کتابخانه‌ها)
python setup.py

# ۳. انتخاب محیط کاری:
# گزینه الف: اجرای داشبورد دسکتاپ گرافیکی (با ظاهر فوق‌العاده پریمیوم)
python gui/guicli.py

# گزینه ب: باز کردن داشبورد متنی زنده در ترمینال
python agicli.py

# ۴. اجرای اولین وظیفه مسیریابی شده از طریق ترمینال
python agicli.py run "refactor the auth module to use JWT"
نیازی به کلید API اختصاصی نیست. این فریم‌ورک کاملاً با کانفیگ‌های محلی و دستیار هوش مصنوعی فعلی شما (Cursor، Windsurf، Antigravity IDE و...) یکپارچه می‌شود.محیط گرافیکی دسکتاپ (Antigravity Manager)در پوشه gui/ برنامه guicli.py قرار گرفته است — یک رابط کاربری دسکتاپ مدرن که بر پایه پایش روندهای اجرا در grok-build طراحی شده و شامل ویژگی‌های زیر است:📡 داشبورد سینک زنده IDE: نمایش زنده ابزارها و دستورات در حال اجرا توسط عامل هوشمند.🚀 نوار پیشرفت بودجه توکن: پایش رنگی و داینامیک مصرف توکن در طول روز و نشست جاری.🛡️ مدیریت کانفیگ و ورود: هماهنگی سریع با تنظیمات محلی ادیتور جهت یکپارچگی دسترسی‌ها.🎯 ترمینال و مجری وظایف: تایپ وظایف و مشاهده لایو مراحلِ چرخه شناختی سیستم.معماری سیستمچرخه شناختی (Grok-Build Inspired Loop)Code snippetflowchart TD

## فازهای شناختی این فریم‌ورک با الگوبرداری از ساختار چندعاملی grok-build، ۵ فاز شناختی زیر را اجرا می‌کند:فاز ۱: 🔀 بازیابی پویای مهارت‌هابه جای بارگذاری کل دستورالعمل‌ها، مسیریاب مهارت‌ها وظیفه را تحلیل کرده و فقط فایل‌های راهنمای مورد نیاز را لود می‌کند.فاز ۲: 🧬 تکامل خودکار (Self-Evolution)در صورت عدم وجود مهارت مرتبط، Meta-Agent ساختار مهارتی جدیدی را از ابتدا تولید، تست و ثبت می‌کند.فاز ۳: 🧠 حافظه اپیزودیک و بازخوردتحلیل خطاهای مشابه گذشته پیش از شروع کار و ذخیره‌سازی سناریوهای موفق/ناموفق برای افزایش هوشمندی در نشست‌های بعدی.فاز ۴: 🔬 تفکر عمیق و ارزیابی (Critic & Sandbox)تغییرات پرریسک ابتدا توسط عامل منتقد (Critic) بازبینی شده و در محیط شبیه‌سازی موقت (Sandbox) تست می‌شوند.فاز ۵: 🎯 عاملیت کنش‌گرا (Proactive Agency)اسکن هوشمند پروژه در زمان‌های بیکاری جهت یافتن باگ‌ها، کدهای مرده و تست‌های جامانده و ارائه پیشنهادهای اولویت‌بندی‌شده.مرجع دستورات CLIBashpython agicli.py [command] [options]
