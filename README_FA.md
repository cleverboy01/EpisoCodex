## تفاوت اصلی این پروژه چیست؟

بیشتر ابزارهای دستیار برنامه‌نویسی فقط یک دستورالعمل (System Prompt) ساده هستند. اما این پروژه یک **سیستم‌عامل هوشمند برای دستیار هوش مصنوعی شماست**:

| ویژگی | ابزارهای معمولی هوش مصنوعی | اپیزوکدکس (EpisoCodex) |
|---|---|---|
| انتخاب مهارت‌ها | دستی | **مسیریابی هوشمند** از طریق روتِر معنایی مهارت‌ها |
| یادگیری از اشتباهات گذشته | وجود ندارد | **حافظه RLHF** — هرگز یک خطا را دو بار تکرار نمی‌کند |
| مصرف توکن | بدون کنترل | **سپر فشرده‌ساز توکن** جلوی کدهای حجیم و خوانش‌های بیهوده را می‌گیرد |
| اعمال تغییرات کد | امیدوارانه و بدون تست | اجرای **سندباکس شبیه‌سازی شده** پیش از دستکاری کد اصلی |
| یادگیری نشست جاری | بعد از بستن ادیتور فراموش می‌شود | **حافظه اپیزودیک** که در نشست‌های بعدی باقی می‌ماند |
| کیفیت کد | بازبینی دستی | **موتور خود‌بازنویسی** که به طور خودکار اصلاحات را اعمال می‌کند |
| مدیریت وظایف | خودتان باید بنویسید | **حلقه خودگردان (AGI Loop)** وظایف را کشف و اولویت‌بندی می‌کند |

## شروع سریع

```bash
# ۱. کلون کردن مخزن
git clone https://github.com/cleverboy01/EpisoCodex.git
cd EpisoCodex

# ۲. راه‌اندازی با یک کلیک (ساخت دیتابیس‌ها، ایندکس مهارت‌ها و نصب کتابخانه‌ها)
python setup.py

# ۳. انتخاب محیط کاری:
# گزینه الف: اجرای داشبورد دسکتاپ گرافیکی (با ظاهر فوق‌العاده پریمیوم)
python gui/guicli.py

# گزینه ب: باز کردن داشبورد متنی زنده در ترمینال
python agicli.py

# ۴. اجرای اولین وظیفه مسیریابی شده توسط AGI از طریق ترمینال
python agicli.py run "refactor the auth module to use JWT"
```

> **نیازی به کلید API نیست.** همه چیز به صورت محلی و با استفاده از دستیار هوش مصنوعی فعلی شما (Cursor، Windsurf، Antigravity IDE و غیره) اجرا می‌شود.

## محیط گرافیکی دسکتاپ (Antigravity Manager)

در پوشه `gui/` برنامه `guicli.py` قرار گرفته است — یک نرم‌افزار دسکتاپ مدرن که با `customtkinter` طراحی شده و شامل ویژگی‌های زیر است:
- **📡 داشبورد سینک زنده IDE:** به صورت زنده نشان می‌دهد چه چیزی در ادیتور می‌نویسید و هوش مصنوعی در حال اجرای چه ابزاری است.
- **🚀 نوار پیشرفت بودجه توکن:** نمایش نوارهای رنگی و داینامیک مصرف توکن در طول روز و نشست جاری.
- **🛡️ اتصال واقعی به اکانت گوگل ادیتور:** با خواندن کانفیگ‌های محلی، اطلاعات ورود شما در گوگل را با داشبورد مدیریتی هماهنگ می‌کند.
- **🎯 ترمینال و مجری وظایف:** وظیفه خود را تایپ کنید و خروجی اجرای AGI را به صورت زنده در نرم‌افزار تماشا کنید.

```mermaid

    B --> C{User Task}
    C --> D[🧠 RLHF Preflight\nCheck past errors]
    D --> E[🔀 Skill Router\nSemantic skill selection]
    E --> F[🎯 Task Execution\nWith selected skills]
    F --> G{Result OK?}
```

## فازهای شناختی

این فریم‌ورک ۵ فاز ارتقای شناختی را روی دستیار هوشمند شما پیاده می‌کند:

### فاز ۱: 🔀 بازیابی پویای مهارت‌ها
نیازی نیست همه مهارت‌ها را وارد کانتکست کنید. **مسیریاب مهارت‌ها** وظیفه شما را به صورت معنایی تحلیل کرده و فقط فایل‌های راهنمای مورد نیاز را لود می‌کند.

### فاز ۲: 🧬 تکامل خودکار (Self-Evolution)
اگر هیچ مهارتی با نیاز شما همخوانی نداشت، **Meta-Agent** یک مهارت جدید از ابتدا طراحی کرده، تست می‌کند و به آرشیو مهارت‌ها اضافه می‌کند.

### فاز ۳: 🧠 حافظه اپیزودیک
قبل از شروع: بررسی خطاهای مشابه قبلی. بعد از پایان: ذخیره سناریوهای موفقیت و شکست. عامل هوشمند در هر بار استفاده باهوش‌تر می‌شود.

### فاز ۴: 🔬 تفکر عمیق سیستم-۲ (منتقد + سندباکس)
تغییرات پر ریسک توسط **عامل منتقد (Critic)** بررسی شده و در یک پوشه شبیه‌سازی موقت (Sandbox) تست می‌شوند تا کدهای اصلی پروژه آسیب نبینند.

### فاز ۵: 🎯 عاملیت کنش‌گرا (Proactive Agency)
زمانی که با ادیتور کار نمی‌کنید، سیستم کدهای شما را برای یافتن باگ‌ها، کدهای مرده و تست‌های جامانده اسکن کرده و کارهای اولویت‌دار را برای تأیید به شما نشان می‌دهد.

## مرجع دستورات CLI

```bash
python agicli.py [command] [options]
```

| دستور | توضیحات |
|---|---|
| `(بدون آرگومان)` | باز کردن داشبورد متنی زنده |
| `run "task"` | اجرای کامل یک تسک در چرخه شناختی AGI |
| `loop [--iterations N]` | اجرای لوپ خود‌اصلاحی مداوم برای بهبود کدها |
| `tokens [--session N] [--daily N] [--unlock]` | مدیریت و مشاهده سهمیه توکن‌ها |
| `scan` | اسکن کل پروژه برای یافتن اولویت‌های بازنویسی |
| `memory "task"` | بررسی خطاهای گذشته در مورد این تسک قبل از شروع |
| `skills [query]` | لیست کردن یا جستجوی معنایی مهارت‌ها |

## موتور بهینه‌سازی مصرف توکن

یکی از اصول طراحی اپیزوکدکس، **مصرف صفر توکن‌های اضافی** است:

* **سپر نگهبان توکن (Token Squeezer Guard):** از خواندن فایل‌های حجیم توسط هوش مصنوعی جلوگیری می‌کند و او را مجبور به استفاده از جستجوهای هدفمند و خوانش بازه‌های کوچکِ خطوط می‌کند.
* **بهینه‌ساز بخش‌ها (Chunk Optimizer):** فایل‌های پایتون را بر اساس متدها و کلاس‌ها تجزیه می‌کند تا ادیتور بتواند تغییرات را به صورت جراحی‌شده روی یک متدِ کوچک اعمال کند (بدون لود کردن کل فایل).
